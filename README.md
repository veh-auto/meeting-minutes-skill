# 会议纪要 Skill

把会议转写文本整理成结构化纪要，自动区分议题、决策和行动项。

## 它能做什么
- 从杂乱的会议转写中提取**议题、决议、行动项**
- 行动项自动标记负责人和截止时间，没有明确负责人的标为“待指定”，不编造
- 输出 Markdown 格式，包含“会议议题”“决议事项”“行动项”三个板块

## 怎么用
1. 下载 `meeting-minutes.zip`
2. 在 WorkBuddy 中导入该 zip
3. 粘贴会议转写文本，说“整理成会议纪要”即可

## 触发词
`整理会议`、`会议纪要`、`会议记录`

## 说明
- 适用于 WorkBuddy 技能系统
- 不依赖外部 API，纯本地文本处理
